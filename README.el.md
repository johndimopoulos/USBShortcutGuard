# USBShortcutGuard — Καθαρισμός USB από ιούς συντομεύσεων για Windows

[English guide](README.md)

Το USBShortcutGuard 3.0 βοηθά στον καθαρισμό μονάδων USB που έχουν προσβληθεί από ιούς συντομεύσεων σε **Windows 10 και Windows 11 (64-bit)**. Μεταφέρει σε καραντίνα αρχεία με ισχυρή υπογραφή ιού συντομεύσεων και επαναφέρει την ορατότητα των αντίστοιχων αρχικών αρχείων και φακέλων.

Αν οι φάκελοι στο USB εμφανίζονται ως συντομεύσεις ή τα αρχεία σας έχουν κρυφτεί, το USBShortcutGuard ελέγχει για ενδείξεις αυτού του τύπου μόλυνσης.

## Λήψη του USBShortcutGuard

[Λήψη USBShortcutGuard 3.0 για Windows](https://github.com/johndimopoulos/USBShortcutGuard/releases/download/v3.0/USBShortcutGuard-Setup.exe) · [Σημειώσεις έκδοσης και άθροισμα ελέγχου SHA-256](https://github.com/johndimopoulos/USBShortcutGuard/releases/tag/v3.0)

1. Κατεβάστε τα **USBShortcutGuard-Setup.exe** και **SHA256SUMS.txt** από τη σελίδα της έκδοσης.
2. Συγκρίνετε το SHA-256 του προγράμματος εγκατάστασης με το παρεχόμενο άθροισμα ελέγχου.
3. Εκτελέστε το πρόγραμμα εγκατάστασης και εγκρίνετε το αίτημα διαχειριστή των Windows.
4. Περιμένετε να ολοκληρωθεί ο έλεγχος πριν ανοίξετε ύποπτες συντομεύσεις.

## Δυνατότητες

- Ελέγχει μονάδες USB που είναι συνδεδεμένες κατά την εκκίνηση και όσες συνδέονται αργότερα.
- Εξετάζει ύποπτες συντομεύσεις, εντολές autorun και σχετικά scripts χωρίς να τα εκτελεί.
- Μεταφέρει σε καραντίνα επιβεβαιωμένα αρχεία ιού συντομεύσεων και επαναφέρει τις ιδιότητες κρυφού αρχείου/αρχείου συστήματος στα αντίστοιχα αρχικά αρχεία.
- Εμφανίζει αποτελέσματα στις ειδοποιήσεις των Windows και πρόοδο για ελέγχους που διαρκούν περισσότερο από πέντε δευτερόλεπτα.
- Παρέχει προβολή καραντίνας μόνο για διαχειριστές, με αντιγραφή και οριστική διαγραφή.
- Υποστηρίζει **Ελληνικά και Αγγλικά**: η ελληνική γλώσσα εμφάνισης των Windows επιλέγει Ελληνικά· κάθε άλλη επιλέγει Αγγλικά.

## Εγκατάσταση και υπάρχουσα εγκατάσταση

Απαιτούνται Windows 10 ή Windows 11, σύστημα 64-bit και έγκριση διαχειριστή. Οι οδηγίες ανοίγουν ξανά από τον φάκελο της εφαρμογής στο μενού Έναρξη.

Η **επανεγκατάσταση/ενημέρωση** διατηρεί τα αρχεία καταγραφής και καραντίνας. Η **πλήρης επανεγκατάσταση** και η **απεγκατάσταση** τα διαγράφουν.

## Συχνές ερωτήσεις

### Μπορεί να επαναφέρει κρυμμένα αρχεία και φακέλους στο USB;

Επαναφέρει την ορατότητα υπαρχόντων αρχικών αρχείων που συνδέονται με επιβεβαιωμένη μόλυνση από ιό συντομεύσεων. Δεν ανακτά το περιεχόμενο διαγραμμένων αρχείων.

### Είναι πλήρες antivirus;

Όχι. Το USBShortcutGuard στοχεύει σε μοτίβα ιών συντομεύσεων σε USB. Δεν αντικαθιστά το antivirus και δεν αφαιρεί μόλυνση από τα ίδια τα Windows. Χρησιμοποιήστε το Windows Defender ή άλλο antivirus για να ελέγξετε έναν μολυσμένο υπολογιστή.

### Μεταφέρονται όλα τα scripts σε καραντίνα;

Όχι. Η επέκταση ενός αρχείου δεν αρκεί για να ενεργοποιηθεί η καραντίνα. Τα συνήθη scripts παραμένουν αμετάβλητα· η ανίχνευση εξαρτάται από το ύποπτο περιεχόμενο και το πλαίσιο χρήσης τους.
